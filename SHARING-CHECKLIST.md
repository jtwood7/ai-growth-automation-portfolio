# Before sharing outside your account

- [ ] Confirm you are authorized to distribute the underlying workflow designs and implementation logic.
- [ ] Inspect diagrams, documentation, code and importable exports for proprietary details.
- [ ] Confirm all customer identities and proof points are fictional or public and authorized.
- [ ] Verify no production keys, credentials, webhooks, instance IDs, private account data or internal URLs remain.
- [ ] Confirm all workflows are inactive and any integrations are clearly mocked, disabled or unfinished.
- [ ] Test importable JSON in an isolated n8n instance without production credentials.
- [ ] Keep this GitHub repository private until review is complete.
- [ ] When inviting an interviewer, explain that access requires their GitHub account.
- [ ] Do not interpret successful standalone scoring tests as end-to-end system integration tests.

This project documents prototypes, not live deployed automation.
